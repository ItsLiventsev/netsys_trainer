# Лаборатория 01 — Обжим витой пары (T568B)

Полностью автономная папка: здесь лежат **все** файлы, которые нужны тренажёру.
Скачайте папку целиком и откройте `index.html` — страница заработает без сервера,
сборки и интернета.

## Как открыть

- **Просто:** двойной щелчок по `index.html`.
- **Через сервер** (рекомендуется, если браузер запрещает `localStorage` для файлов):

  ```bash
  python3 -m http.server 8000     # затем http://localhost:8000
  ```

При открытии по `file://` прогресс может не сохраняться — тренажёр покажет
предупреждение и продолжит работать; результат всё равно считается и отправляется в МЭШ.

## Что внутри

```
index.html          разметка страницы, CSP, подключение файлов
favicon.svg         иконка
css/
  base.css          дизайн-токены, сброс, типографика
  components.css    шапка, степпер, панели, общие сцены, тосты, модальные окна
  report.css        отчёт, мини-тест, кольцо оценки, печать
  sim.css           сцены этой лаборатории: стриппер, лоток, RJ-45, кримпер, тестер
js/
  vendor/           общий код (копии из общей папки репозитория)
    core.js         DOM-хелперы, тосты, drag&drop, хранилище, LMS
    icons.js        иконки, жилы, схемы стандартов, кольцо оценки
    shell.js        оболочка: степпер, инструменты, подсказки, чек-лист, режимы
    report.js       фабрика шага «Отчёт»
  data.js           жилы, T568A/T568B, инструменты, теория, тест, настройки
  graphics.js       SVG-арт коннектора и кримпера
  state.js          модель состояния, баллы, payload для МЭШ
  steps.js          шаги 1–6: зачистка, раскладка, коннектор, обжим, тестер
  report.js         конфигурация отчёта этой лаборатории
  app.js            сборка оболочки, навигация, восстановление прогресса
```

## Правки

- Код лаборатории (`data.js`, `graphics.js`, `state.js`, `steps.js`, `report.js`,
  `app.js`, `css/sim.css`) редактируется прямо здесь.
- Файлы в `js/vendor/` и три общих `css` — копии. Их правят в общей папке репозитория,
  затем запускают `npm run build`; `npm test` падает, если копии разошлись с оригиналом.
  Поэтому не редактируйте файлы с баннером «Сгенерировано…» вручную — изменения
  затрутся при следующей сборке.
