# Смена на узле связи — монтаж коммутационной панели

Квест-смена по теме **«Монтаж коммутационной панели»** (УП.01 Учебная практика,
специальность 09.02.06 «Сетевое и системное администрирование»).

Ситуационная задача: техник ООО «СетьПолис» приходит на объект — складской комплекс
«Северный», кроссовая К-2. Заявка **PP-314**: смонтировать патч-панель 24 × RJ-45 Cat 6A
в стойку ШТК-2, заделать восемь портов по **T568B**, промаркировать линии, проверить
тестером и сдать работу с документацией по образцу ГОСТ.

Панель, кабель, нож, тестер и стойка — реальные: страница ведёт по сюжету, держит
операционную карту, тайм-бокс ротации бригад, журнал кроссовой и акт.

## Восемь эпизодов

| № | Эпизод | Что делает студент |
| --- | --- | --- |
| 1 | Узел связи, 08:30 | выбирает, с чего начинается смена; отмечает уровень |
| 2 | Заявка PP-314 | читает заявку и чат объекта, берёт роль в бригаде, заключает договор бригады |
| 3 | Инструктаж и инструмент | пять пунктов допуска, мини-кейс по ОТ, сбор набора из девяти позиций |
| 4 | Что оставил Толик | аудит чужой работы: четыре улики, диагноз, оформление дефекта |
| 5 | Как устроена панель | конструкция, 1U, IDC, T568B, порядок жил, кросс-план по журналу |
| 6 | Работа у стойки | операционная карта из восьми этапов, тайм-бокс ротации, самоконтроль |
| 7 | Тест, приёмка, документация | тест по восьми портам, журнал кроссовой, приёмка мастером |
| 8 | Разбор смены | пять контрольных вопросов, рефлексивная мишень, акт и выгрузка |

## Два формата работы

- **Формат А — стойка:** одна бригада монтирует панель, вторая в это время в симуляторе
  разбирает кейс этого же объекта. Каждые 20 минут — ротация по тайм-боксу.
- **Формат Б — симулятор:** заявка, диагноз, кросс-план, теория, документация, рефлексия.

## Оценивание (100 баллов)

| Критерий | Баллы |
| --- | --- |
| Подключение и раскладка по T568B (набор, диагноз, жилы, теория) | 30 |
| Качество монтажа и кабельного менеджмента (карта из 8 этапов) | 25 |
| Работоспособность портов (тест 8 портов + приёмка мастера) | 20 |
| Документация и отчёт (поля, вывод, печать, выгрузка) | 15 |
| Ответы на контрольные вопросы | 10 |

90–100 — «Отлично», 75–89 — «Хорошо», 60–74 — «Удовлетворительно», ниже 60 —
«Неудовлетворительно». Результат уходит в МЭШ сообщением `LMS_SCORE`.

## Как открыть

Папка самодостаточна: скачайте её и откройте `index.html` (или используйте
`https://<user>.github.io/<repo>/simulators/patch-panel/`). Внешних запросов нет —
шрифты Golos Text и JetBrains Mono лежат в `fonts/` вместе с лицензиями OFL.
