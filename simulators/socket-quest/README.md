# Смена в СетьПолисе — квест-тренажёр

Ситуационная задача по теме **«Монтаж сетевых розеток»**: не «собери розетку мышкой»,
а один рабочий день стажёра в ООО «СетьПолис» — заявка INC-2147, кабинет 214,
сломанная линия Р-3, разговор с мастером, операционная карта и сдача смены.

Студент выполняет работу **руками** с реальным инструментом, а страница ведёт его по
сценарию: лор, цели эпизода, диалоги, подсказки, разбор ошибок и контрольные вопросы.
Страница полностью автономна: скачайте папку и откройте `index.html` — интернет не нужен.

## Что внутри

## Оценивание — 100 баллов

| Критерий | Баллы |
|----------|-------|
| Правильность подключения (T568B) — набор, диагностика, теория, порядок жил | 30 |
| Качество фиксации жил — операционная карта, 8 этапов | 25 |
| Работоспособность линии — тест и подтверждение мастера | 20 |
| Оформление отчёта — ФИО, группа, вывод | 15 |
| Ответы на контрольные вопросы | 10 |

Шкала: 90–100 — отлично, 75–89 — хорошо, 60–74 — удовлетворительно, ниже 60 — работу
нужно переделать. Итог отправляется в МЭШ сообщением `LMS_SCORE` (score/maxScore),
прогресс хранится в `localStorage['netsys.quest.state.v1']`.

## Особенности

- **Один экран, один эпизод.** Переход открывается, когда эпизод закрыт по делу, а не по клику.
- **Разбор вместо запрета.** Неверный ответ не блокирует навсегда: показывается, почему так,
  и можно исправить — но баллы за попытки уже сняты.
- **Клавиатура.** Все действия — кнопки и чекбоксы, «дальше» листается мышью, Enter/Space
  и стрелками в рельсе; фокус видимый, есть скрытый статус для скринридеров.
- **Печать.** «Акт» печатается отдельным листом: только документ, без интерфейса.
- **Без интернета.** Ни CDN, ни внешних шрифтов; CSP запрещает сетевые запросы.

## Сброс и продолжение

Прогресс сохраняется автоматически. «Сбросить смену» в шапке очищает состояние
(с подтверждением). Повторное открытие страницы возвращает на текущий эпизод.
